# Validator Agent — Deprecated Name

> **Deprecated:** New documentation and implementations should use [`Evidence Review Agent`](evidence-review-agent.md).

This file remains temporarily so older links and project history do not break.

The term **Validator Agent** blurred a governance boundary by implying that an AI system could validate learning. OpenLab now reserves **Human Validation** for the authorized human process.

The AI role is **Evidence Review**: organize evidence, surface gaps and contradictions, map evidence to rubric dimensions, identify uncertainty, and prepare questions.

> **AI REVIEW ≠ HUMAN VALIDATION**

See [`../docs/TERMINOLOGY.md`](../docs/TERMINOLOGY.md).
