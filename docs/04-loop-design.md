# Loop Design

OpenLab starts with closed single loops, then grows into controlled fleet loops, and only later explores open loops.

## Closed single loop

Best for early repo work and classroom-safe prototypes.

```text
Human Goal
  ↓
Single Agent Draft
  ↓
OLA Self-Check
  ↓
Human Review
  ↓
Revision
  ↓
Commit / Portfolio Update
```

## Controlled fleet loop

Best for a full OpenLab mission.

```text
Human Goal
  ↓
Mr. V Orchestrator
  ↓
Portfolio Curator Agent
  ↓
OLA Review Agent
  ↓
Validator Agent
  ↓
Teacher Approval
  ↓
Portfolio / Badge / Chapter
```

## Core principle

Single loops build quality. Fleet loops build scale. OLA keeps both honest.
