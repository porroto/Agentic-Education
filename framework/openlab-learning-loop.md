# OpenLab Learning Loop

```text
Mission
  ↓
AI Collaboration
  ↓
Creation
  ↓
Evidence Collection
  ↓
Reflection
  ↓
Human Validation
  ↓
Recognition
  ↓
Portfolio Growth
```

## Description

The OpenLab Learning Loop helps learners document not only what they made, but how they changed while making it.

## Key question

What happened to the learner's thinking while working with AI?
